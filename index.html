Delivered Size Notes

Three notes about the places where a hosted image model quietly does something other than what the request said: the size it actually generated at, the lettering it drew instead of set, and whether you should be calling the API at all.

The common thread is that all three are decided outside the prompt. No amount of better phrasing reaches them, which is why they rarely appear in prompt guides and regularly appear in post-mortems.

  • Requested size is not delivered size

  • Why the letters come out wrong

  • An API key, or a browser tab

Kept by Andy Swift, who also builds a browser interface for OpenAI's GPT Image 2.5 that prints what actually ran. Independent; not affiliated with OpenAI.
